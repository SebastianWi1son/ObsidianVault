# 预习笔记规则（第 20~37 课，未学部分）

> 产出全部在 `cpp_preview/`，命名 `P{课号} - {英文主题}.md`。
> 预习笔记与 `cpp_redraft/` 的复习笔记性质不同：是**学之前**的讲解，不是**学之后**的总结。

## 预习笔记固定结构

1. **开篇**：1~2 句——本课在课程链中的位置 + 一句话说清"这课的存在解决什么问题"
2. **`## 1. 这课为什么存在`**：用 1~3 个"没有它会怎样"的痛点讲动机，`>` 引用块写本质一句话
3. **★重点小节**：项目常用/重要的知识点，每个按「为什么需要（解决什么问题）→ 怎么用（老师源码短示例）→ 易错点」展开，标题带 **★重点**
4. **○了解一节**：不常用知识每条一句话点到
5. **预习提问**：4~8 个编号问题（直接问 + 代码问），针对★重点，**不写答案**——留给学完的你回来解答

## 重点判断标准

学习目的是**尽快上手 C++ 做项目**（后续课程是 Boost.Asio 网络编程），所以：
- 智能指针、lambda/std::function、移动语义/完美转发、模板、虚函数多态、容器选型、RAII → **重点深挖**
- 菱形继承、SFINAE 细节、手写轮子的实现细节、冷门运算符重载 → **了解即可**

## 风格

沿用 `_笔记规则.md`（cpp_redraft 内）：编号 `##` 小节、`-  **关键词**` 极简 bullet、短代码块带注释、中文为主术语英文。差异：语气是给"还没学的人"讲解，可比复习笔记稍展开，仍忌长篇大论。
