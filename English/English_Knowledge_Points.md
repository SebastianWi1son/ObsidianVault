## 二、语法硬伤（反复出现）

| # | 错误 | 正确 | 要点 |
|---|---|---|---|
| 1 | is that mean | **does that mean** | 实义动词疑问句用 do/does。is that...? 后只能接名词/形容词 |
| 2 | would happens | **does happen** | 情态动词后永远接动词原形；客观事实用一般现在时 |
| 3 | we gonna try work | we**'ll be working** | gonna 是口语拼写；we gonna 缺 be 动词；try work 缺连接 |
| 4 | hope it clear | I hope that**'s** clear | 缺系动词 is |
| 5 | only can copy | **can only** copy | 情态动词在前，副词在后：can only / will just |
| 6 | that mean | That **means** | 三单。固定记：That means… |
| 7 | it make c looks | it **makes** C **look** | 使役结构 make + 宾语 + 动词原形 |
| 8 | i learn that | I**'ve learned** that | "刚了解到"是已完成动作，用完成时 |
| 9 | it nearly replace | **they've largely replaced** | 主语复数 → they；已发生的变化用完成时 |
| 10 | consider to 适配 | consider **matching** | consider 后接动名词：consider doing ✅ / consider to do ❌ |
| 11 | how about make | how about **making** | how about / what about 后接名词或动名词 |
| 12 | capable of select | capable of select**ing** | capable of + 动名词 |
| 13 | dont know what it'll be used | what it's used **for** | 句尾介词不能丢：use X for Y → what it's used for |
| 14 | most of sdk are | most **SDKs** are / most of **the SDKs** are | most of 后面必须接限定的复数 |
| 15 | if there're 2 cpp project | if **a project has two .cpp files** | 数量词落错了名词 |
| 16 | only g++ would cause…? | **would** compiling… **cause**…? | 疑问句要倒装：把 would 提到句首 |
| 17 | the test result're | the test **results were** | result're 不是合法缩写；复数用 results |
| 18 | a origin variable | **an** original variable | 元音开头用 an |
| 19 | the namespace | namespace**s** | 泛指一类语言机制，用复数裸名词，不加 the |
| 20 | didnt exist | **doesn't** exist | 说一般情况用现在时 |

## 五、语域与习惯（影响分数）

| # | 错误 | 正确 | 要点 |
|---|---|---|---|
| 1 | u / ive / didnt / gonna / kinda / wont | 写全：you / I've / didn't / going to | 短信体缩写在 IELTS 里直接扣分，最容易改、收益最大 |
| 2 | 自称 user | 自称 **I** | 跟 agent 直接对话，自称 user 很生硬（像在写需求文档） |
| 3 | dev / src code | development / source code | 聊天里缩写没问题，正式写作写全 |
| 4 | c / cpp | **C** / **C++** | 语言名大写 |
| 5 | i enjoy the simple use of X | I **like how simple X is** | 语法没错但生硬。母语者说 I like how simple it is |
| 6 | my embedded dev is X-style | my embedded **projects use** the X style | dev 是活动，不能"是某风格"；让项目做主语 |
| 7 | take a brief introduction to me | **give me** a brief introduction | 方向反了：介绍是对方给你的 |

## 六、技术术语（英文技术写作）

| # | 错误 | 正确 | 要点 |
|---|---|---|---|
| 1 | the bash content | the **terminal** output | bash 是命令解释器，不管窗口/选中/剪贴板；那些归终端模拟器管 |
| 2 | the linker is the instructor | the linker is the **coordinator** | 链接器是协调者，不是教员 |
| 3 | without the other cpp included | without **linking** the other .cpp **file** in | .cpp 文件之间是链接（link），不是包含（include）——include 是 .h 的事 |
| 4 | optional version in code | the standard is chosen **at compile time** | 标准由命令行 -std= 决定，不在代码里 |
| 5 | 向下兼容 | **backward compatible** | backwards 也可，美式常省 s |
| 6 | #pragma (指代 #pragma once) | 写全 **#pragma once** | #pragma 只是指令开头，后面能接几十种功能，单说指代不明 |

## 七、值得单独记住的三个模式

1. **实义动词的疑问句要用 do/does** — is that mean ❌ → does that mean ✅（08-06 Block 04/07、08-07 多次）
2. **介词搭配靠记，不能从中文推** — differ from（不是 with）、on disk（不是 in）、consider doing（不是 to do）
3. **情态动词在前，副词在后** — can only / will just，疑问句再把 can 提到句首：Can I only use it…?（08-07 Block 01/05 两次重犯）

## 八、歧义警示（影响理解时必须指出）

> `the english instruction's the hide line between the conversation and technine build`

单看这半句有两种理解：
- **A**：英文指令是**分界线**（英语批改和技术工作要分开）
- **B**：英文指令是贯穿两者的**暗线**（英语学习藏在技术工作里同步进行）

本意是 B。要表达 B：
> English runs as an **undercurrent** through everything we do here.
> — 或：Treat English as a **background thread** woven into the technical work, not a separate track.

**用词提示**：`hide` 是动词，不能直接修饰名词。「暗线」对应 undercurrent（潜流）、background thread（后台线程）、running thread（贯穿的线索）。**没有 hide line 这个说法**。
